# 주제 기반 구간 분할 (outliner 도입)

## 문제

현재 파이프라인은 자막을 **15분 고정 격자**로 자른다(`transcript.py:73`, `CHUNK`). 경계가 내용과 무관한 곳에 그어지므로 노트가 "주제 단위 블록"이 아니라 "15분마다 끊은 타임라인"이 된다.

실측 사례 — `notes/260818_한경-모닝루틴.md`: `김 수출`·`BYD 플릿 판매`·`무학 ELS` 세 토픽이 Part 1 끝과 Part 2 앞에 **통째로 두 번** 실렸다. 앞뒤 120초 겹침 설계의 부작용이 아니라, 토픽 한가운데를 15분 격자가 지나갔기 때문이다.

**HMW:** 어떻게 하면 구간 경계를 시계가 아니라 영상의 주제 전환이 정하게 할 수 있을까?

## 방향

`glossary` 와 병렬로 **`outliner` 에이전트를 신설**하고, 그 산출물(주제 경계 목록)로 `transcript.py` 가 `part-NN.txt` 를 자른다. 시간순은 유지한다 — 경계만 주제가 정한다.

```
transcript.py "<URL>" --outline-only     ← transcript.txt + 제목/채널
   → 사용자에게 영상 유형 확인 (제목·채널로 추측한 선택지 제시)
   ├─ glossary  ─┐ (병렬)
   └─ outliner  ─┘  ← 유형별 기준·목표 구간 수를 프롬프트로 받음
transcript.py "<URL>" --segments "0-264,264-549,..." --overlap 30
   → section-note ×N (병렬) → synthesizer → auditor
```

`glossary` 를 확장해 경계까지 뽑게 하는 안(에이전트 수 유지)은 기각했다. 순수한 관심사 분리 때문이 아니라 **실패 비용이 다르기 때문**이다. 용어집이 틀리면 표기가 조금 거칠어지는 정도지만, 경계가 틀리면 노트 전체 구조가 망가진다. 병렬이라 시간 비용도 없다.

**영상 유형은 사용자에게 묻는다.** 에이전트가 "이 영상은 경계가 뚜렷한가"를 추론하게 두지 않는다. `--probe` 로 자막 지연을 사람에게 확인받는 것과 같은 자리이고, 같은 이유다(잴 수 없는 것은 묻는다). 제목·채널명은 `oembed` 로 이미 들어오므로(`transcript.py:85`) 추측을 기본 선택지로 띄우고 사용자는 확인만 한다.

## 유형별 손잡이

| 유형 | 구간 수 | 겹침 | outliner 경계 기준 |
|---|---|---|---|
| 뉴스 브리핑형 | 최대 8개 | 30초 | 기사·토픽 전환에서 자른다. 상한을 넘으면 인접 토픽을 묶고 제목에 `·` 로 나열한다 |
| 강의·해설형 | 최대 5개 | 120초 | 개념 단위로 자른다. 앞 개념 위에 쌓아 올리는 대목은 자르지 마라 |
| 대담·인터뷰형 | 최대 8개 | 60초 | 질문·화제 전환에서 자른다. 길이가 들쭉날쭉해도 맞추지 마라 |

**길이 대역은 두지 않고 개수 상한만 둔다.** 초안에는 `4~10분` / `8~20분` 대역이 있었으나 검증에서 부작용이 나왔다(아래 참조). 구간 길이는 주제가 정하게 두고, 병렬 `section-note` 수만 상한으로 제어한다.

겹침이 유형마다 다른 것이 핵심이다. 뉴스는 토픽이 독립적이라 30초로 충분하고 이때 통째 중복이 사라진다. 강의는 앞 개념이 뒤에서 계속 쓰이므로 120초를 유지해야 한다. 현재는 전부 120초라 뉴스에서 중복이 났다.

**경계 근거는 자막의 화제 전환 문장에서 찾게 한다.** 검증에서 두 에이전트 모두 `"자, 다음 기사입니다"`, `"getting back to how any of this actually works"` 같은 실제 전환 발화를 경계 근거로 삼았다. 추측이 아니라 자막에 있는 신호를 쓴다는 뜻이므로 프롬프트의 명시적 지침으로 승격한다.

`transcript.txt` 의 줄 형식은 `[HH:MM:SS] 텍스트` 다(`[MM:SS]` 아님). outliner 프롬프트에 정확히 적어야 한다.

## 검증 결과 (2026-08-20)

`.work/` 에 남은 뉴스(`62b87kW6cC8`, 38분 한국어 자동자막)와 강의(`aircAruvnKk`, 18분 영어 수동자막)에 outliner 프롬프트만 적용해 outline을 뽑아 대조했다. 노트는 재생성하지 않았다.

- [x] **유형과 기준을 준 상태에서 outliner가 쓸 만한 경계를 낸다.** 뉴스 8구간의 경계 타임스탬프 7개를 `grep` 으로 대조한 결과 **전부 자막의 화제 전환 문장 첫 줄에 정확히 일치**했다(`[00:09:09] 자, 다음 기사입니다...`, `[00:33:46] 자, 이제 오늘 프리마켓...`). 추정한 시각이 아니다.
- [x] **중복 기재가 해소된다.** 15분 격자에서 Part 1·2에 통째로 두 번 실렸던 `김 수출`(11:56)·`BYD`(14:26)·`무학 ELS`(16:25)가 각각 3구간·4구간에 한 번씩만 들어갔다.
- [x] **경계 절단이 강의형을 나쁘게 만들지 않는다.** 현행 격자는 18분 영상을 `0–15분` + `15–18:25`(3분짜리 꼬리)로 잘랐다. 새 경계는 5개 개념 단위(문제 제기 / 뉴런·층 구조 / 은닉층 기대 / 가중치·편향·시그모이드 / 함수로 보기)로 떨어졌고 설명이 이어지는 중간을 끊지 않았다. **경계 확신도 폴백은 불필요.**
- [x] **구간이 8개로 늘어도 병렬 `section-note` 비용이 감당된다.** 뉴스가 정확히 상한인 8개를 냈고, 한 메시지 동시 실행 한도 안이다.

**발견된 문제 — 길이 하한이 무관한 토픽을 강제 병합한다.** 초안의 `4~10분` 대역 때문에 뉴스 outliner가 3분 미만 토픽(빵값 인상, 스트레이키즈, 부동산세)을 시간상 인접한 기사에 붙였다. 그 결과 3구간에 `무순위 청약`(부동산)과 `김 수출`(산업)처럼 서로 무관한 토픽이 섞였다. 에이전트는 NOTE에 이 사실을 스스로 적었다. → 길이 대역을 제거하고 개수 상한만 남겼다.

다만 뉴스는 토픽이 25개쯤이라 상한 8을 두는 한 병합 자체는 불가피하고, 그 병합 기준은 결국 시간 인접이다. 코넬 표는 행 단위로 토픽을 나누므로 노트 본문 품질에는 영향이 작다고 보고 수용한다.

**전체 파이프라인 재실행에서 나온 규칙 변경 — 겹침 기록 금지.** 8구간을 실제로 생성해 조립해 보니 겹침 30초 때문에 **완전 중복 행이 4개** 생겼다(파리바게뜨·실리콘투/공모주·JYP·엔비디아가 인접 두 구간에 모두 기록됨). 기존 `겹친 부분의 내용도 그냥 적어라` 는 **15분 격자 시절의 규칙**이다. 경계가 토픽 한가운데를 지나가니 겹친 내용을 적지 않으면 내용이 통째로 날아갈 위험이 있었기 때문이다. 이제 경계가 화제 전환 문장에 놓이므로 그 위험이 없다.

→ 규칙을 **"겹침은 문맥 파악용으로만 읽고, 기록은 본구간 범위로 한정한다"** 로 바꿨다. 겹침의 원래 목적(경계 직전에 한 번 언급된 고유명사를 다음 구간 에이전트가 놓치는 것 방지)은 유지되고 중복 행만 사라진다.

부수 효과로 **구간 간 모순도 사전에 차단된다.** 실제로 겹침 구간의 같은 사실을 두 에이전트가 다르게 적었다 — 실리콘투 `5.02% 올라` vs `5.02% 하락`, KT `1.71% 오른` vs `1.71% 하락`. 한 구간만 적으면 이 충돌 자체가 생기지 않는다.

## MVP 범위

들어가는 것:
- `transcript.py --outline-only` (transcript.txt 만 생성, 분할 없음)
- `transcript.py --segments "lo-hi,lo-hi,..." --overlap N` — `split_parts()` 의 `lo, hi` 생성부만 교체(10줄 미만)
- SKILL.md 에 `outliner` 절 + 유형 확인 절 + 위 손잡이 표
- `--selftest` 에 임의 경계 분할 assert 추가

빠지는 것: 위 3단계 이후는 현행 그대로. `section-note`/`synthesizer`/`auditor` 프롬프트는 건드리지 않는다.

## 안 하는 것

- **주제별 재배열 / 2단 계층 목차** — 시간순 유지를 선택했다. 같은 주제가 영상 앞뒤로 흩어져 있어도 묶지 않는다. 영상과 대조하며 보는 용도를 깨뜨린다.
- **경계 목록 사용자 승인 체크포인트** — 자동 확정을 선택했다. 유형을 이미 묻고 있으므로 확인 단계를 두 번 두지 않는다.
- **저해상도 2-pass 스캔** — 실측 기각. `transcript.txt` 가 38분에 49KB이므로 3시간 영상도 ~230KB로 서브에이전트 컨텍스트 하나에 들어간다. 먼저 요약해서 경계를 잡을 이유가 없다.
- **침묵 구간 기반 기계 절단** — 자동생성 자막에는 침묵 정보가 없다. 잴 수 없는 것을 재는 척하는 안이다.
- **경계 확신도 폴백** — 유형을 묻는 것으로 대체됐다. 위 두 번째 베팅이 깨지면 그때 되살린다.

## 열린 질문

- outliner 경계가 자막 줄 경계와 어긋날 때(토픽 전환이 한 줄 중간에서 일어날 때) 어느 쪽으로 붙일 것인가 — 현재 `split_parts()` 는 `lo <= t < hi` 라 자연히 뒤 구간으로 간다. 그대로 둘지 확인 필요.
- 유형 선택지에 "모르겠음/기타"가 필요한가. 필요하면 기존 15분 격자가 그 기본값이 된다.
