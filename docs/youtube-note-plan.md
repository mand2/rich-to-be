# YouTube 영상 → 코넬/옥스포드 노트 스킬

## Context

유튜브 영상을 구조적으로 파악하기 위해 코넬 노트 형식의 정리본을 만들고 싶다. 영상 전체 길이를 파악해 15분 단위 sub-note로 쪼개고, 각 구간을 2단 표(단서/필기)로 정리한다. **요약·정리만 하고 평가·판단은 하지 않는다.**

논의를 거쳐 확정된 것:

- **형태: Claude Code 스킬** (마크다운 1개). Python CLI/웹앱 대비 만들기·수정하기가 압도적으로 싸고, 대화하면서 다듬을 수 있음. API 키 불필요.
- **자막 수급: NotebookLM에서 복붙.** NotebookLM에 YouTube URL을 소스로 넣으면 자막 + 타임스탬프를 얻을 수 있음. **1차 가공은 시키지 않는다** — 요약의 요약이 되어 정보가 소실되므로, 자막 원문만 받아서 가공은 전부 Claude가 한다.
- 브라우저 자동화(`claude-in-chrome` MCP)는 이 세션에 미연결. 완전 자동화가 필요해지면 그때 붙인다.

## 만들 것

**파일 1개**: `rich-to-be/.claude/skills/youtube-note/SKILL.md`

리포 안에 두어 git으로 버전관리한다. 트레이드오프: 이 리포 디렉토리 안에서 작업할 때만 스킬이 활성화된다. 어디서든 쓰고 싶어지면 `~/.claude/skills/` 로 심볼릭 링크를 걸면 된다 —

```sh
ln -s "$PWD/.claude/skills/youtube-note" ~/.claude/skills/youtube-note
```

### 프론트매터

```yaml
---
name: youtube-note
description: Use when the user pastes a YouTube transcript or asks to summarize a video into structured notes. Produces Cornell/Oxford-style notes split into 15-minute sub-notes with a two-column cue/notes table. Triggers on "유튜브 노트", "코넬 노트", "영상 정리", "/youtube-note", or a pasted timestamped transcript.
---
```

### 스킬 본문 — 처리 절차

1. **입력 검증** — 타임스탬프가 붙은 자막이어야 함. 없으면 진행하지 말고 타임스탬프 포함 버전을 요청한다.
2. **전체 길이 파악** — 자막 마지막 타임스탬프 = 영상 길이.
3. **구간 분할** — `ceil(전체길이 / 15분)` 개의 sub-note. 15분 미만이면 1개. 마지막 구간은 짧아도 그대로 둔다 (65분 → 5개, 마지막 5분).
4. **문서 생성** — 아래 형식.
5. **저장 + 출력** — `notes/<영상제목-슬러그>.md` 로 저장하고, 채팅에도 전문 출력.

### 문서 형식

**헤더**

```markdown
# <영상 제목>

- **핵심 주제**: <1줄 정의>
- **타깃 난이도**: <입문 / 중급 / 고급> — <전제 지식 1줄>
- **영상 길이**: <HH:MM:SS> · **구간 수**: <N>
```

**구간별 sub-note** (N회 반복)

```markdown
## Part 1 — 00:00–15:00 | <구간 소주제>

| 단서/키워드 (Cues & Questions) | 핵심 필기 내용 (Detailed Notes) |
| --- | --- |
| `[02:14]` **용어**<br>Q. 복습용 자가 질문? | - 정의<br>- 동작 원리 / 메커니즘<br>- 장단점·트레이드오프<br>- 실무 코드 / 사례 |

**Summary**: <구간 내용 2~3줄 요약>
```

- 좌측: 핵심 용어, 복습용 자가 질문, 다이어그램/흐름 키워드. 각 행 첫머리에 `[MM:SS]` 타임스탬프를 붙여 영상으로 되돌아갈 수 있게 한다.
- 우측: 개조식 bullet로 압축 서술.
- **주제가 바뀔 때마다 행을 나눈다.** 한 행에 여러 주제를 밀어넣지 않는다.

### 절대 규칙 — 판단 금지

스킬에 명시적으로 박아둘 내용. 이게 이 스킬의 핵심 제약이라 애매하게 두면 안 된다.

**금지**

- 평가 ("이 접근은 훌륭하다", "설명이 부실하다")
- 추천 ("~하는 게 좋다", "실무에서는 B를 쓰세요")
- 중요도 순위 매기기 (영상에서 강조하지 않은 것을 강조하지 않는다)
- 영상에 없는 배경지식·보충 설명 추가
- 화자 주장의 사실 여부 검증이나 반박

**허용**

- **화자의 판단을 사실로 기록하는 것** — "화자는 A가 B보다 빠르다고 설명" 은 요약이지 판단이 아니다. 이 구분이 핵심이다.
- 구조화, 소제목 붙이기, 순서 재배열 (내용을 바꾸지 않는 선에서)
- **타깃 난이도 표기** — 사용자가 명시적으로 요청한 항목이므로 유일한 예외. 화자가 전제하는 선행지식으로부터 판정하고, 근거를 1줄로 병기한다.

**언어**: 영상이 외국어여도 노트는 한국어. 핵심 기술 용어는 원어 병기 — `역전파(backpropagation)`.

## 검증

1. **실제 자막으로 1회 실행** — NotebookLM에서 자막을 뽑아 붙여넣고 `/youtube-note` 실행. 확인 항목:
   - 구간 수가 `ceil(길이/15분)` 과 맞는가
   - 마크다운 표가 깨지지 않는가 (셀 안 줄바꿈에 `<br>` 사용)
   - 타임스탬프가 실제 영상 위치와 맞는가 (2~3개 샘플로 영상에서 직접 확인)
   - `notes/*.md` 파일이 생겼는가
2. **판단 금지 위반 검사** — 생성된 노트를 훑어 "좋다/나쁘다/추천/주의" 류 표현이 있는지 확인. 있으면 스킬의 금지 규칙을 강화한다.
3. **짧은 영상 1회** — 15분 미만 영상으로 sub-note가 1개만 나오는지 확인.

## 이번에 안 하는 것

- 자막 자동 수급 (yt-dlp / youtube-transcript-api) — NotebookLM 복붙으로 충분. 배치 처리가 필요해지면 그때.
- 브라우저 자동화 — 복붙 마찰이 실제로 거슬리면 `claude-in-chrome` 붙인다.
- Python CLI 이식 — 프롬프트가 곧 결과물이라, 스킬에서 형식을 다듬은 뒤 옮기면 재작업이 거의 없다.
