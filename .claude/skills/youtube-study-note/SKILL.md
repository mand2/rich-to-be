# 유튜브 스터디 노트

영상을 '요약'하는 게 아니라 **다시 안 봐도 되는 학습 자료**로 재구성하는 스킬이다.
일반 요약과의 차이는 세 가지다. 화자의 비유와 말투를 그대로 보존하고, 결론이 아니라 결론까지 가는 논리 단계를 분해하고, 영상 밖에서도 쓸 수 있는 원칙으로 한 번 더 추상화한다.

## 1. 입력 확보

**필요한 것은 타임스탬프가 포함된 자막 전문이다.** 링크만으로는 영상을 볼 수 없으므로 자막이 없으면 시작할 수 없다.

**이 리포에서는 먼저 `transcript.py` 를 시도한다.** 자막을 자동으로 받아오므로 사용자에게 붙여넣기를 시키지 않아도 된다.

```sh
.venv/bin/python scripts/transcript.py "<URL>" --outline-only
```

`.work/<video_id>/` 에 타임스탬프가 찍힌 `transcript.txt` 와 `meta.json`(제목·채널·길이·원본 URL·자동자막 여부)이 생긴다. `--outline-only` 는 구간 분할을 건너뛴다 — 스터디 노트는 전문을 한 번에 읽으므로 분할이 필요 없다.

`meta.json` 의 `auto_generated` 가 `true` 면 표시 지연 보정 2.2초가 **자동으로 적용된다. 사용자에게 확인을 묻지 않는다.** 측정값이 아니므로 푸터에 `(미측정 기본값 2.2초 보정)` 이라고 밝히고, 사용자가 타임스탬프 어긋남을 알려올 때만 `--lag <초>` 로 다시 뽑는다 (절차: `scripts/caption-lag.md`).

스크립트가 없거나 자막이 없는 영상이면 그때 사용자에게 요청한다. 이렇게 안내하면 된다.

> PC 유튜브에서 영상 아래 `...더보기` → **스크립트 표시** → 패널 우측 점 3개 메뉴는 **건드리지 말고**(타임스탬프가 있어야 인용이 가능하다) 전체 선택해서 붙여넣어 주세요.

헤더 재료는 `.work/<video_id>/meta.json` 에 다 있다 — `title` · `author` · `upload_date`(KST 업로드일) · `duration` · `url`. **헤더 날짜는 `upload_date` 를 쓴다** (파일명의 yyMMdd 와 다른 값이다). 자막만 받은 경우처럼 meta.json 이 없으면 자막에서 유추하거나 헤더에서 생략한다. **추측해서 지어내지 않는다.**

자동 생성 자막은 오타와 띄어쓰기 오류가 많다. 문맥상 명백한 오인식(예: 금융 영상에서 "채권" → "채건")은 조용히 고쳐 쓰되, 의미가 갈리는 대목은 원문 표기를 유지한다.

## 2. 자막 읽기

노트를 쓰기 전에 자막을 훑으면서 다음 다섯 가지를 먼저 찾아낸다. 이 다섯 개가 곧 문서의 뼈대가 된다.

1. **한 줄 결론** — 화자가 이 영상으로 하고 싶었던 말 한 문장
2. **출발점이 된 프레임** — 본론에 들어가기 전 깔아 둔 비유나 대비 구도
3. **설명 없이 넘어간 용어** — 시청자가 모를 수 있는데 화자가 당연하게 쓴 개념들
4. **결론에 이르는 단계** — "그래서", "그런데", "그러면 왜"로 이어지는 논증의 마디
5. **인용할 만한 육성** — 화자 특유의 표현, 단정, 농담

## 3. 문서 구조

기본 골격은 아래와 같다. 영상 성격에 따라 섹션을 빼거나 이름을 바꿔도 되지만, **용어 사전 → 논리 흐름 → 인사이트** 3단 구성은 이 노트의 정체성이므로 유지한다.

```
헤더        카테고리 라벨 · 제목 · 채널 | 날짜 | 길이 | 원본 링크
한 줄 결론   강조 박스. 영상 전체를 한 문장으로. 필요하면 단서 한 문장 추가
01 도입     영상의 출발점이 된 프레임/비유 + 해당 구간 타임스탬프
02 용어 사전 등장 개념 정의 (한글 + 영문 병기)
03 논리 흐름 결론까지 가는 단계를 번호로 분해
04 인사이트  영상 밖에서도 통하는 원칙 3~5개
05 지켜볼 것 관전 포인트 / 체크리스트 / 다음 액션
푸터        출처 및 면책 한 줄
```

**영상 유형별 조정**

| 유형 | 조정 |
|---|---|
| 시장·이슈 해설 | 위 구조 그대로 |
| 강의·튜토리얼 | 03을 "단계별 절차"로, 05를 "직접 해볼 것"으로 |
| 인터뷰·대담 | 02 축소, 03을 "쟁점별 입장"으로, 화자 구분 표기 |
| 리뷰·비교 | 03을 "평가 항목별 판정"으로, 비교표 추가 |

## 4. 각 섹션 작성 규칙

### 한 줄 결론
영상을 안 본 사람이 이것만 읽고도 논지를 파악할 수 있어야 한다. "~에 대해 설명한다" 같은 메타 서술 금지. 화자의 주장을 그대로 진술한다.

- 나쁨: 미국 국채 금리 상승의 원인을 분석하는 영상이다.
- 좋음: 최근 금리 급등은 미국에 대한 불신이 아니라 수급 때문이다. CDS가 미동도 없는 것이 그 증거.

### 02 용어 사전
각 항목은 **정의 1~2줄 + 보조 설명 한 줄** 두 층으로 쓴다. 보조 설명에는 성격에 맞는 라벨을 붙인다.

- `비유 —` 화자가 쓴 비유를 그대로 옮길 때
- `쉽게 —` 정의를 더 풀어써야 할 때
- `읽는 법 —` 지표라서 해석 방법이 필요할 때
- `포인트 —` 오해하기 쉬운 지점을 짚을 때

화자가 만든 비유가 있으면 **반드시 그것을 쓴다.** 더 나은 비유를 알고 있어도 대체하지 않는다. 화자의 언어를 보존하는 것이 이 노트의 핵심 가치다.

### 03 논리 흐름
각 단계는 `제목 + 타임스탬프 + 설명 2~3줄 + 직접 인용 1개` 형태다. 인용은 큰따옴표로 감싸고 자막 원문 그대로 옮긴다.

단계 사이의 연결이 보이게 쓴다. 독립된 요약 다섯 개가 아니라, 1번이 있어야 2번이 성립하는 사슬이어야 한다.

### 04 인사이트
**여기가 가장 중요하고 가장 자주 망하는 섹션이다.** 영상 내용의 반복이 아니라, 다른 상황에도 적용되는 원칙으로 한 단계 올려야 한다.

- 반복(나쁨): 미국 CDS가 안 움직였으므로 파산 걱정은 과도하다.
- 원칙(좋음): 공포의 크기는 뉴스가 아니라 가격으로 잰다 — 걱정에 돈을 거는 시장이 조용하다면 실제 공포는 크지 않다.

각 항목은 굵은 한 줄 제목 + 설명 2~3줄. 3~5개면 충분하다.

### 05 앞으로 지켜볼 것
영상이 남긴 미결 사항. 날짜가 있는 이벤트, 임계값, 전환 신호를 구체적으로 적는다. "관심을 갖고 지켜보자" 같은 공허한 문장은 넣지 않는다.

## 5. 지켜야 할 선

전체 목록은 `references/rules.md` 에 있다. 아래는 그중 이 문서의 정체성을 이루는 것들이다.

**자막에 없는 정보를 넣지 않는다.** 배경 지식으로 보강하고 싶어도 하지 않는다. 이 문서의 가치는 "영상에 있던 것만 담겨 있다"는 신뢰에서 나온다. 자막만으로 뜻이 통하지 않는 대목은 억지로 채우지 말고 그대로 두거나 생략한다.

**화자의 주장과 사실을 구분한다.** 특히 투자·건강·법률처럼 판단이 개입되는 주제는 푸터에 출처와 면책을 명시한다. 예: `유튜브 자동 생성 자막 전문을 바탕으로 정리. 발언자의 견해이며 투자 판단의 근거가 아닌 학습 자료입니다.`

**노트의 언어는 영상의 언어를 따른다.** 사용자가 달리 요청하지 않는 한, 한국어 영상은 한국어 노트로 만든다.

## 6. 출력

HTML 아티팩트 한 페이지로 만든다. 마크다운으로는 이 문서의 레이아웃이 나오지 않는다.

레이아웃과 CSS는 `references/layout.md`에 있다. **HTML을 쓰기 전에 반드시 읽는다** — 특히 인쇄 시 카드가 페이지 경계에서 잘리는 문제를 막는 규칙이 들어 있다.

파일명은 `notes/<폴더>/{yyMMdd}_<슬러그>.html` 이다 — 날짜는 **노트를 만드는 오늘 날짜**다. 영상 방송일이 아니다 (방송일은 헤더에 적는다).

저장 폴더는 **본문을 쓰기 전에 사용자에게 한 번 묻는다** — "투자 / 부동산 / 개인 공부용 중 어디인가요?" 사용자가 이미 말했으면 묻지 말고 그대로 따른다.

| 답 | 경로 |
|---|---|
| 투자 노트 | `notes/invest/` |
| 부동산 노트 | `notes/real-estate/` |
| 개인 공부용 | `notes/self-study/` |
| 모닝루틴 영상 | `notes/morning-routine/` (묻지 않고 여기) |

문서를 만든 뒤에는 브라우저 인쇄(Ctrl/Cmd+P) → PDF로 저장하면 된다고 한 줄로 알려준다.
