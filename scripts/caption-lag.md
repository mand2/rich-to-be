# 자동생성 자막 지연 보정

`meta.json` 의 `auto_generated` 가 `true` 면 **기본값 2.2초가 자동으로 적용된다.** 사용자에게 확인을 요청하지 않는다. 수동 자막이면 보정이 없다.

자동자막은 실제 발화보다 늦게 찍히고 그 폭이 영상마다 다르다. 자막 데이터만으로는 잴 수 없다 — 기준선이 될 같은 언어의 수동 자막이 필요한데, 그게 있으면 애초에 자동자막을 쓰지 않기 때문이다. 그래서 2.2초는 측정값이 아니라 기본값이다. **노트 헤더/푸터에 `(미측정 기본값 2.2초 보정)` 이라고 밝힌다.**

타임스탬프가 영상과 눈에 띄게 어긋난다고 사용자가 알려오면, 그때만 대조한다:

```sh
.venv/bin/python scripts/transcript.py "<URL>" --probe
```

초반 120초를 `원본 / 보정후` 두 열로 뽑아 준다. 사용자에게 **보정후 시각에 그 말이 실제로 나오는지 영상에서 확인**해 달라고 요청하고, 답을 받아 다시 뽑는다:

```sh
.venv/bin/python scripts/transcript.py "<URL>" --lag 3.5
```

- 말이 **아직 안 나왔으면** → `--lag` 를 줄인다 (보정 과다)
- 말이 **이미 지나갔으면** → `--lag` 를 늘린다 (보정 부족)
